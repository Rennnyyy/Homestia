# Homestia — Angular frontend

The Homestia web facade. It is a **thin consumer** of the published Aletheia
frontend packages (`@rennnyyy/aletheia-tokens`, `-core`, `-ui`) and the
`@rennnyyy/aletheia-cli` code generator. Platform behaviour lives in the SDK;
only Homestia's own pages, AI composer, stage wizard, accent axis, skin and
i18n dictionaries live here.

## Development

```bash
npm install                 # needs the @rennnyyy registry (see .npmrc)
npm start                   # ng serve + Tailwind build, API proxied to :5000
```

The app expects the backend on `http://localhost:5000` (dev proxy in
`proxy.conf.json`). Alternatively build the facade into the host and run the
.NET program:

```bash
npm run build               # outputs into ../Homestia/src/Program/wwwroot
dotnet run --project ../Homestia/src/Program --urls http://localhost:5080
```

## Code generation

`src/app/entities/**` is generated by `@rennnyyy/aletheia-cli` from the
committed `model.json` snapshot — never edit it by hand.

```bash
npm run generate-entities   # regenerate from model.json
npm run codegen:check       # drift gate (run in CI)
```

## Testing

```bash
npm test                    # Vitest via the Angular unit-test builder
npm run test:coverage       # + enforced coverage floors (see Test-Coverage.md)
npm run test:e2e            # Playwright against a FRESH host (empty store)
npm run test:e2e:update     # regenerate the visual baselines deliberately
```

The e2e suite compares committed pixel baselines, so it needs a freshly started
host (`E2E_BASE_URL` overrides the default `http://localhost:5080`); a warm host
accumulates records and diffs the table for data reasons. Two of the five tests
run at phone width and assert the drawer's geometry — nothing spills out of the
bar or the panel.

## Structure

- `src/app/app.html` / `app.ts` — the shell: the SDK's `aletheia-sidebar` (destinations, drawer, collapse), a single header bar, one chrome control per axis
- `src/app/features/*` — the two entity pages (properties, rentals)
- `src/app/shared/components/*` — AI assistant panel + wizard, accent picker
- `src/app/core/*` — accent axis, Homestia skin, shape vocabulary
- `libs/ui/*` — local spartan primitives; only the accordion has no SDK equivalent
- `e2e/*` — Playwright smoke + committed visual baselines
